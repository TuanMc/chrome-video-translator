# chrome-video-translator

A Chrome extension that generates near-real-time Vietnamese subtitles for whatever audio/video is playing in the current tab (English, Japanese, or Chinese source audio). Everything runs locally — speech recognition and translation both happen on your own machine, with no paid cloud AI APIs and no audio/transcript ever leaving localhost during normal use.

## Project layout

This repo is three independently-runnable pieces:

| Folder | What it is | Runs on |
|---|---|---|
| [`extension/`](extension/README.md) | The Chrome extension itself (React + TypeScript + Vite) — tab audio capture, popup settings, subtitle overlay. | Chrome |
| [`nllb-server/`](nllb-server/README.md) | Local backend: `faster-whisper` speech-to-text + `facebook/nllb-200-distilled-600M` translation, both in-process. **Default engine.** | `localhost:8000` |
| [`libre-server/`](libre-server/README.md) | Local backend: same speech-to-text, but translates via a self-hosted **LibreTranslate** container instead of NLLB. | `localhost:8001` |

You only need **one** server running to use the extension — the popup's "Translation Engine" setting picks which one a session talks to. Both can run at the same time if you want to switch between them without restarting anything. Neither backend is a strict upgrade over the other (NLLB is more reliable on Japanese and technical terms; LibreTranslate is more natural on casual English register/slang) — see [`libre-server/README.md`](libre-server/README.md) for the measured comparison.

For a deeper look at how the whole system fits together — architecture diagrams, the WebSocket protocol, every internal dependency — see [`aidlc-docs/inception/reverse-engineering/`](aidlc-docs/inception/reverse-engineering/), a project knowledge base generated by reading the actual code (start with `architecture.md`).

## Running it locally

### 1. Build and load the extension

```bash
cd extension
npm install
npm run build
```

Then in Chrome: go to `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select `extension/dist`.

### 2. Start a translation backend

Pick one (or both — they run on different ports and don't conflict):

**NLLB (default, no extra setup)**:
```bash
cd nllb-server
python3 -m venv .venv
.venv/bin/pip install --index-url https://download.pytorch.org/whl/cpu torch
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```
Or, with no Python install at all: double-click `nllb-server/run-server.bat` (Windows) with Docker Desktop installed.

**LibreTranslate (needs a second container for the translation engine)**:
```bash
cd libre-server
docker compose up -d --build
```
Or without Docker: see [`libre-server/README.md`](libre-server/README.md) for the venv + standalone-container path.

First run downloads the AI models (a few minutes, needs internet) — later runs are fast. Check readiness at `http://127.0.0.1:8000/health` (or `:8001` for libre-server).

### 3. Use it

Open a video/audio page, click the extension icon, pick a source language and translation engine, click **START TRANSLATION**. The tab's audio keeps playing normally; a subtitle overlay appears once speech is recognized and translated.
